zProject for Windows x64
========================

1. Extract the entire zProject-win-x64 folder from the zip.
2. Run zProject.exe.

The bundle is self-contained and includes the .NET runtime, zProject operator,
mobile server, and all zUI content files. Microsoft Edge WebView2 is the only
Windows component used by the desktop UI; it is included with current Windows
10 and Windows 11 installations and is also installed by Microsoft Edge.

Do not move an individual executable out of this folder. The application and
its companion tools expect the adjacent content directories to remain present.
